# AIDX 주간 결과물 · 피드백

물리치료과 1학년 AIDX 수업(3인 1팀, 근골격계 질환 프로젝트)의 주간 결과물 제출과 교수 피드백 웹앱입니다.
A반 4조 + B반 5조 = 9개 조, 조 이름 + 학번 + 접속 코드로 로그인합니다.

- `index.html` — 웹앱 전체
- `config.js` — Supabase 연결 정보 (Project URL, Publishable key)
- `vercel.json` — 새 버전이 바로 반영되도록 캐시 끄기

## 학생
처음에는 '처음 가입'에서 조·학번·이름·내 접속 코드·수업 가입 코드를 넣어 가입합니다. 다음부터 조 선택 → 학번 → 접속 코드로 로그인 → 주차를 골라 결과물 제목·내용·링크·첨부(파일당 2MB, 5개)를 제출합니다.
같은 조원 누구나 제출·수정할 수 있고, 교수 피드백(코멘트·점수·완료/보완 요청)을 확인합니다.

## 교수 (관리자)
'교수' 탭에서 관리자 아이디와 접속 코드로 로그인합니다.
- 현황판: 9개 조 × 주차 표, 칸을 눌러 제출물 확인과 피드백 작성
- 주차 관리: 15주 고정, 제목·설명·마감·잠금
- 조·학생 관리: 학생 추가(접속 코드 자동 생성), 코드표 인쇄
- 설정: 학생 가입 허용/닫기·수업 가입 코드·조당 인원, 전체 제출·피드백 CSV 내려받기, 교수 코드 변경

주의: config.js에는 Publishable(anon) key만 넣습니다. secret / service_role 키는 절대 넣지 마세요.
