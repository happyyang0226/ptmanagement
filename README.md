# 물리치료 환자관리 기록지 (APTA 6단계)

검진 → 평가 → 진단 → 예후·치료계획 → 중재 → 결과를 기록하는 교육용 웹앱입니다.

- `index.html` — 웹앱 전체 (한 파일)
- `pt-exam-backup.schema.json` — '내보내기' 백업 파일(JSON)의 구조
- `vercel.json` — 새 버전을 올리면 바로 반영되도록 캐시를 끄는 설정

## 기록 옮기기
기록은 각 브라우저에 저장됩니다. 이전 파일에서 **내보내기**로 JSON을 저장한 뒤,
배포된 웹 주소에서 **기록 가져오기 (JSON)**로 불러옵니다. (가져오면 현재 목록이 백업 내용으로 바뀝니다.)

## 업데이트
새 버전 HTML의 이름을 `index.html`로 바꿔 GitHub 저장소에 다시 올리면 Vercel이 자동으로 다시 배포합니다.
